# FUTURE_FS_02_Client_Lead_Management_System

## 📌 Project Overview

A Client Lead Management System (Mini CRM) developed as part of the Future Interns Full Stack Web Development Internship.

This application helps businesses manage client leads, track lead status, organize follow-ups, and maintain customer information efficiently.

## 🚀 Features

* User Authentication
* Dashboard with Lead Statistics
* Add New Leads
* Update Lead Information
* Delete Leads
* Lead Status Tracking
* Search and Filter Leads
* Responsive User Interface

## 🛠️ Technologies Used

* React.js
* JavaScript
* HTML5
* CSS3
* Tailwind CSS
* Vite

## 📂 Project Structure

* Dashboard
* Lead Management
* Authentication Module
* Settings Module
* Analytics & Statistics
